# 22doce Deco Hogar · demo de tienda online

Demo de la tienda de 22doce Deco Hogar (bazar, regalería y decoración, Santa Fe 310). Sitio estático: HTML, CSS y JavaScript.

- `index.html`: tienda con categorías, catálogo, carrito y pedido por WhatsApp.
- `admin.html`: panel para cargar productos, ver pedidos, reseñas de Google y pedir reseñas a clientes.

Los productos, fotos (Pexels) y reseñas son de ejemplo. En la demo, el panel guarda los cambios solo en el navegador de quien los hace.
